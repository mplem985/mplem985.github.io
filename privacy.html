Email Digest: Privacy Policy

Last updated: 12 October 2026

Email Digest is a private tool used only by its owner to summarise their own email accounts. It is not offered to the public.

What data is accessed

With the account owner's permission (Google OAuth, read-only scope gmail.readonly), the tool reads messages in the inbox that arrived since its previous run: sender, subject, date and message text. It cannot send, change or delete email.

How the data is used

  • The sender, subject, date and a shortened version of each message (at most about 1,500 characters) are sent to the Anthropic API (Claude) to decide which emails need attention.
  • A short summary is sent to the owner's own Telegram chat.
  • Nothing is used for advertising, sold, or shared with anyone else.

Storage

Email contents are not stored. The tool keeps only the access tokens, the time of its last run, and run logs (counts, no message contents), on a private server that only the owner can access.

Google API Services User Data Policy

Email Digest's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
